## 🛠️ Task 01 Overview: Sales Data Analysis Using Codex

### **Objective**
Build an end-to-end Python sales analysis workflow using **OpenAI Codex / GitHub Copilot** as a coding assistant to analyze business metrics and visualize sales performance.

### **Workflow & Approach**
1. **Data Loading & Preprocessing:** Read `sales_data.csv`, parse dates, and check data integrity using Pandas.
2. **Exploratory Data Analysis (EDA):** Derived business KPIs (Total Revenue, Average Order Value, Total Orders) using NumPy and Pandas aggregation.
3. **Data Visualization:** Built multi-panel figures using Seaborn and Matplotlib to highlight monthly revenue trends, top-performing cities, category distributions, and discount impacts.
